# MediConnect
This is an application used to book appointment for health check ups to an hospital i have created this website using Angular Frontend and backend nodejs+express
# 🏥 MediConnect

MediConnect is a full-stack Hospital Appointment System that helps patients easily find doctors and book appointments.

## ✨ Features

- User Registration & Login
- JWT Authentication
- View Doctors
- Book Appointments
- View Appointments
- Doctor Availability
- Admin Dashboard
- Protected Routes

## 🛠️ Technologies Used

- Angular
- TypeScript
- HTML & CSS
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- Postman
